# NIMIQ MyIndex ⚡

NIMIQ MyIndex is a lightweight, zero-backend Web3 app that tracks real-world purchasing power and inflation metrics on-chain using the Nimiq network.

## 🚀 Features
- **Ultra-compact Payload:** Encodes market conversions (USDT & BTC Satoshis) and local product prices into payloads under 64 bytes.
- **On-Chain Oracle:** Anchors real-world commodity rates directly into Nimiq transactions.
- **Dynamic Analytics:** Displays history and interactive charts filtering between products and currency pairs.
- **100% Client-Side:** Zero server costs, privacy-preserving, and instant execution.

## 🛠️ Tech Stack
- HTML5 / CSS3 / JavaScript (ES6+)
- `@nimiq/hub-api` for Wallet interaction
- `@nimiq/identicons`
- Chart.js for visualization
